# Paper Atlas Windows 应用

双击 `PaperAtlas.exe`。启动窗口管理本地服务，完整研究界面在默认浏览器打开；不需要 Python、VS Code 或 Codex 插件。关闭浏览器标签不会停止任务；点击启动窗口的“退出应用”会停止任务。

请保留整个 `PaperAtlas` 文件夹（包括 `_internal` 和 `codex`），不要单独移动 exe。当前构建位于项目的 `dist/PaperAtlas`，会自动使用项目中的 `config.toml` 和 `runs`，能浏览已有研究。把整个应用文件夹复制到其他位置时，使用该文件夹自己的配置和 `runs`，历史研究需另行复制。

## 订阅登录与 Astra 终审

1. 在“文献查询”或“审阅与问题”中点击“登录订阅账号”，用具有 **Codex 使用权限的 ChatGPT 账号**完成官方浏览器登录。
2. 登录完成后自动更新模型列表。默认保留 `gpt-6-astra`；若当前账号没有该模型，界面会说明原因，由你手动选择其他模型。不会自动替换。
3. 打开有阅读卡片的研究，进入“审阅与问题”，选择模型及推理强度，点击终审按钮。
4. 新的审阅记录显示进度、审查意见和补读需求。仅当模型明确批准且应用的引用覆盖、分类和文件一致性检查通过时，才生成最终报告。

此方式不需要 OpenAI API Key。用量归属于 Codex 订阅，仍受套餐额度、模型权限和网络状态限制。其他厂商的 coding plan 不等于 Codex 订阅；必须使用实际支持 Codex 的账号。应用不会用 API 付费调用作为降级方案。

本应用的登录缓存位于 `.app-data/codex`，不读取或复制 VS Code 的登录令牌，不修改用户目录里的 Codex 配置。首次需单独登录。此目录包含登录凭据，不要分享。构建包不包含登录凭据。

## 下层 Flash 与检索

下层始终使用 `config.toml` 中配置的 Flash 模型和该供应商自己的调用方式、密钥与额度，Codex 订阅不包含这些模型。若没有对应调用额度，可填写手动英文检索词查询 arXiv、浏览已有结果，并对已有阅读卡片启动订阅终审。自然语言检索式生成与新论文的 Flash 阅读仍需要对应 Flash 的可用配置。

研究重点由你在“我的研究需求”中自由填写；支持方法、实验数据、指标、硬件与基线等要求。候选论文和论文库可按时间排序。

## 审阅范围与数据

应用向所选 Codex 模型发送完整研究需求、阅读卡片、从本地保存原文重新定位的引文上下文、筛选边界及上一轮审阅意见。该模式审查关键证据上下文，不代表已逐页重新阅读全部论文。历史记录若没有原文存档，可以生成审查意见和待补证据清单，但不能直接获得批准。

每次终审创建新研究记录，保留原结果。模型没有写文件权限，由应用校验结构化输出并保存。任务失败、停止或断网不会自动重复提交，也不会自动升级模型。查看“文献查询”中的任务列表可以找到全部新审阅记录。

运行数据、登录缓存、临时文件和构建产物均写在项目/应用目录中。不安装系统服务，不添加开机启动项。

## 从源码重新构建

在项目虚拟环境中安装 `pyinstaller>=6.12,<7`，确保 `codex` 命令可用，执行 `build-app.ps1`。此脚本把本机官方 Codex 可执行程序及相邻资源复制到应用目录，不复制用户配置或凭据。

依据官方 [Codex App Server](https://learn.chatgpt.com/docs/app-server) 的账号登录、模型列表和任务接口实现。源代码启动：`.venv\Scripts\python.exe -B -m deepseek_survey.desktop`。
