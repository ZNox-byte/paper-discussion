# Codex 最终审查记录

## 审查结论

本轮 32 篇论文的 Flash 阅读结果均已通过项目的证据与结构校验，DeepSeek v4 Pro 也完成了唯一主分类和结构化综合。Codex 对 Pro 草稿进行内容级复核后，结论为：**覆盖完整，分类总体合理，但技术关系需要修订后发布**。本轮已按下述决定改写正文，并保留原始 `report_pro.md` 作为阶段产物。

审查后的最终正文坚持两条原则：

1. “主题相近”不自动等于“后作改进前作”；没有阅读卡片证据时，只写成研究轨迹上的相关、替代或分支。
2. 分类内可以有多个并行主线，不为追求首尾衔接而把并行系统强行串成一条链。

## 覆盖与分类核验

- 32 个任务 ID（P01–P32）全部存在，没有遗漏、重复主分类或虚构 ID。
- 主分类形成完整分区：推理服务与请求调度 8 篇、KV Cache 与内存管理 13 篇、并行计算与分布式执行 1 篇、训练系统与优化 1 篇、模型压缩与低精度计算 5 篇、性能评测与成本分析 3 篇、可靠性/弹性/可观测性 1 篇。
- “异构硬件与内核优化”没有独占的主分类论文，但它确实是跨类别主题，主要体现在 P03、P08、P17、P18、P19、P25、P26、P31。最终报告将其写成横切层，不为凑齐类别而重复归类。

## 主要关系修订

### 推理调度

- P15 Nexus 与 P05 NanoFlow 都优化单 GPU 服务，但阅读卡片没有证明 Nexus 是 NanoFlow 的后继改进。修订为“机制相关的并行分支”：前者做 prefill/decode 的动态 SM 分区，后者做 nano-batch 与资源操作重叠。
- P14 DynaServe 不再写成 P06 Llumnix、P27 QLM 的线性后继。三者分别以 KV 迁移、全局队列控制、micro-request 与动态解耦为控制手段，是同一问题空间中的替代路径。
- P13 与 P12 都处理公平性和缓存/切换成本，但没有足够证据支持论文谱系式继承。最终报告仅将 P13 写为在研究目标上进一步联合公平性与前缀局部性。

### KV Cache 与内存管理

- 保留 P01 PagedAttention 与 P03 vAttention 的替代关系；保留 P24 在 PagedAttention 块管理之上加入 token 级虚拟化的机制扩展。删除 P24 对 P03 的前驱依赖，因为阅读卡片支持的是正交关系。
- 将 Pro 草稿中的长存储链拆成三组：P11 为状态化多级缓存基础；P17 SSD、P18 CXL、P19 分层 I/O/调度是不同介质和数据路径的兄弟分支；P23 则是按请求、按层、面向 SLO 的细粒度放置分支。它们不再被叙述成依次改进。
- P20 已经是“自适应”选择压缩算法、压缩率和设备放置，故删除“P20 使用固定压缩策略”的错误表述。P21 的准确定位是把目标进一步扩展为压缩与驱逐的联合优化。
- P22 不再被写成 P20→P21 的下一段线性优化。它改变了正确性机制：用有损 KV 生成草稿，再以全量 KV 验证，属于保障输出一致性的正交扩展。

### 低精度与压缩

- P25 可视为 P07 的方法级细化：同为 2-bit KV 路线，并加入层间差异预算与专用内核。但最终报告不把这种技术承接夸大为已核实的引用谱系。
- P10 的核心是 KV 编码、压缩和流式传输，不是 P07/P25 的顺序后继；改为网络与上下文加载分支。
- P26 的在线—离线混合量化和硬件/MMU 协同是另一条实现路径，不再写成必然承接 P25。
- P08 优化的是注意力计算内核，不是 KV 表示本身，单列为低精度算子分支。

### 评测与可靠性

- P04 与 P28 都研究生产负载，后者扩大到更多模型形态并提供生成框架；由于阅读卡片没有证明直接论文继承，最终写成“范围扩展的研究轨迹”。
- P29 是 vLLM 配置的能耗、性能和准确率评测，属于正交验证层，而不是生产负载数据集的线性后继。
- P30 单独形成可靠性主线，并作为反向约束提醒：性能优化中的缓存共享、并发调度和状态复用同时扩大了故障与隔离风险。

## 事实与措辞审查

- 最终正文删除了无法从 Flash 卡片直接支持的论文间因果措辞，并避免复述 Pro 草稿中重复或过强的引用链。
- 数值、实验环境和局限的详细内容保留在逐篇 Flash 阅读卡片中；正文只保留对分类和演进叙事必要的定性结论。
- “直接改进”只在设计目标和机制确有连续性时使用，并明确它是基于本轮材料的技术关系判断，不等同于作者引用关系或历史优先权证明。
- 每篇论文的详细卡片及 arXiv 链接继续从 Pro 报告原样并入最终报告，以便追溯阶段证据。

## 审查边界

本次 Codex 审查以项目内的 32 份 Flash 阅读卡片、其中保存的原文引文、Pro 结构化结果和本地运行产物为依据；没有在这一阶段重新下载并逐页复读全部 PDF。因此，最终报告适合作为结构化研究综述和后续精读导航，不应被当作对作者引用图、历史优先权或全部实验可复现性的独立证明。

## 发布决定

**通过，但须采用 Codex 修订版正文。** `report_pro.md` 保留为 DeepSeek v4 Pro 草稿；`report_final.md` 作为本轮对外阅读的最终版本。
